## Description

A Jupyter notebook containing SageMath code used to create plots in the paper **D. Banerjee, B. Kane, M. Zindulka: Moments of positive traces of Frobenius and false theta functions**.

SageMath, the Sage Mathematics Software System (Version 9.5), 2026, https://www.sagemath.org.

## First cell

Change the parameters M, m, n to produce different plots.

## Second cell

Saves the plots as .png images.
